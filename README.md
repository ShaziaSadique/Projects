## 🔐 John the Ripper — Password Cracking Lab
Hands-on lab testing 5 JtR attack modes (Single Crack, Wordlist, Rules-Based, Incremental, Hybrid/Mask) against 4 password hash types (MD5, SHA-256, SHA-512crypt/yescrypt, bcrypt) on Kali Linux — comparing cracking speed and success rate across all 25 combinations.

**Tools:** Kali Linux, John the Ripper, openssl, htpasswd
